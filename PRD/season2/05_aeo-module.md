# AEO 모듈 — AI가 인용하는 글 만들기 (3벌 공통)

> AEO = Answer Engine Optimization. 챗지피티·퍼플렉시티·네이버 AI·구글 AI 개요가 **답변에 우리 글을 근거로 끌어다 쓰게** 만드는 최적화.
> 검색 순위(SEO)와 별개 층. 노출 전략 3벌(홈피드100/반반/검색100) **전부에 공통 적용**한다.
> AI 인용 규칙(04번 6장)이 "인용할 때 지킬 것"이라면, 이 모듈은 "우리 글이 인용당하게 만드는 것".

---

## 1. 왜 중요한가 (대표 지시 반영)

사람이 검색 안 하고 AI에게 물어보는 시대. AI가 답할 때 우리 글을 출처로 달면 = 무한 무료 노출 + 권위. 병원·변호사처럼 "믿을 근거"를 찾는 분야는 AI 인용이 곧 신뢰·전환.

## 2. AI가 인용하기 좋은 글의 7가지 특징 (프롬프트에 반영)

| # | 특징 | 글에 넣는 법 |
|---|------|-------------|
| 1 | **두괄식 답변** | 각 소제목 바로 아래 첫 문장에서 결론·정의를 먼저 말한다. AI는 첫 문장을 추출한다. |
| 2 | **자기완결 문장** | 앞뒤 맥락 없이도 뜻이 통하는 단문. "이것은/그건" 대명사 대신 주어를 명시. ("도수치료는 ~이다") |
| 3 | **질문형 소제목** | 실제 검색·질문 형태 그대로. "임플란트 비용은 어떻게 정해지나요?" → AI가 Q에 매칭. |
| 4 | **구조화 데이터** | 정의·단계·비교·조건을 목록·표·번호로. AI는 구조화된 블록을 우선 인용. |
| 5 | **구체 팩트(엔티티)** | 숫자·기간·조건·기준을 명시. "보통 3~6개월", "그라프트당 단가" 등 추출 가능한 사실. |
| 6 | **FAQ 블록** | 글 끝에 자주 묻는 질문 3~5개 Q&A. AI 답변에 가장 잘 뽑히는 형식. |
| 7 | **출처·근거·전문성** | 통계엔 출처, 주장엔 근거, 글쓴이 이력(E-E-A-T). AI는 근거 없는 문장은 안 뽑는다. |

## 3. 3벌 공통 필수 삽입 (전략 무관 항상)

- **핵심 질문 1문장 + 즉답 1문단**을 도입부 직후 또는 첫 소제목에 배치(두괄식).
- **글 끝 FAQ 블록** 3~5개(질문형 소제목 + 2~3문장 자기완결 답변).
- 정의·기준·비교는 **표 또는 번호 목록**으로 최소 1개.
- 수치·조건엔 **구체 값**과 (있으면) **출처**.

## 4. 전략별 강도 조절 (충돌 방지)

AEO가 3벌에 다 들어가되, 전략 성격을 해치지 않게 강도만 조절:

| 전략 | AEO 적용 강도 |
|------|--------------|
| 검색 100% | 풀 적용 — 두괄식·표·FAQ·엔티티 전부. AEO와 검색SEO는 시너지. |
| 홈피드 50:검색 50 | 중간 — 두괄식 답변 1개 + FAQ는 유지, 표는 선택. 스토리 흐름 우선. |
| 홈피드 100% | 약하게 — 스토리·공감 우선. 단 글 끝 FAQ 1블록과 핵심 즉답 1문장은 유지(스토리 깨지 않는 선에서). |

> 원칙: AEO는 "덧대는 층"이지 스토리를 밀어내지 않는다. 홈피드형은 사람 감정 우선, AEO는 최소 삽입.

## 5. 검수 연동 (04번 체크리스트에 AEO 항목 추가)

발행 전 체크리스트에 추가:
- [ ] 두괄식 즉답 문장/문단이 있는가
- [ ] 글 끝 FAQ 블록(3~5개)이 있는가
- [ ] 표 또는 번호 목록 1개 이상(검색100·반반), 홈피드100은 FAQ만 필수
- [ ] 수치·주장에 근거/출처가 붙었는가(인용 규칙과 연동)

## 5-1. AEO 효과 측정 (미비점 수정 — AI 인용은 직접 추적이 어려움)

AI가 우리 글을 인용했는지 직접 아는 API는 없음. 대리 지표로 측정:
1. **월 1회 샘플 체크(수동)**: 주요 발굴 키워드를 퍼플렉시티·ChatGPT·네이버 AI에 질문 → 답변 출처에 우리 글 도메인 뜨는지 기록.
2. **AI 봇 방문 추적(자동)**: 서버 로그에서 GPTBot·PerplexityBot·ClaudeBot 등 AI 크롤러의 우리 글 방문 수·유입 referral 집계.
3. **선행지표**: 발행 글 중 FAQ 블록·두괄식·구조화 데이터 적용률(우리가 통제 가능) = AEO 준비도 지표.

→ 1·3은 출시와 함께, 2는 개발 여유 시. 완벽 측정보다 "방향 확인"이 목적.

## 6. 프롬프트 슬롯 (생성 프롬프트에 넣을 지시문)

```
# AEO — AI가 이 글을 답변 근거로 인용하게 만든다 (강도: {{전략별 강도}})
- 각 소제목 첫 문장에서 결론·정의를 먼저 말한다(두괄식).
- 문장은 앞뒤 맥락 없이도 뜻이 통하게 쓴다(주어 명시, 대명사 최소).
- 소제목은 실제 질문 형태로 단다.
- 정의·기준·비교는 표나 번호 목록으로 최소 1개(홈피드100은 생략 가능).
- 수치·기간·조건은 구체 값으로, 통계는 출처와 함께.
- 글 끝에 FAQ 3~5개(질문 + 2~3문장 자기완결 답변)를 넣는다.
```
