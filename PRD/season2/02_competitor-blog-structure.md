# 병원·변호사 대표키워드 상위 블로그 구조 분석

> 조사일: 2026-07-03 · 방법: 네이버 검색 API(블로그) 상위노출 글 6개 대표키워드 분석
> 대상 키워드: 이혼소송변호사 / 형사전문변호사 성범죄 / 음주운전변호사 초범 / 임플란트 가격 / 도수치료 정형외과 / 탈모병원 비용
> 한계: 네이버가 본문 직접 크롤링을 차단(WebFetch·크롬 모두) → 제목 + 본문 앞 200자로 패턴 추출. 실제 글자수·이미지 개수는 시즌2 크롤러(Camoufox)로 재확인 필요.

---

## 1. 상위노출 = 전부 "지역 + 대표키워드" 롱테일 (검색 100% 전략)

병원·변호사 대표키워드 상위글은 예외 없이 **[지역]+[키워드]+[후킹구]** 제목. 예:
- 강남임플란트치과 가격 차이 나는 이유는
- 서초음주운전전문변호사 초범이라면
- 서울도수치료정형외과, 받기 전 확인할 3가지 기준

→ **시사점: 병원·변호사는 "검색 100%" 프롬프트가 주력.** 홈피드형(공감·스토리) 글은 이 대표키워드 상위에 거의 없음. 시즌2에서 업종 = 병원/변호사면 노출 전략 기본값을 검색100으로 제안.

---

## 2. 제목 공식 (후킹구 5종)

| 후킹구 유형 | 예시 | 심리 |
|------------|------|------|
| 이유·차이 호기심 | "가격 차이 나는 이유는", "차이를 고려하는 이유" | 왜? 클릭 유도 |
| 숫자 리스티클 | "받기 전 확인할 3가지 기준", "무혐의 받아내는 3가지 전략" | 정리·신뢰 |
| 상황 가정 | "초범이라면", "초범이라도 안심할 수 없는" | 내 얘기 |
| 결과 약속 | "무혐의 받아내는", "불송치 결정을 받아낸" | 성과 증명 |
| 체크·기준 | "선택 기준이 달라지기까지", "우선 확인해야 할 점" | 판단 도움 |

지역명은 거의 항상 맨 앞. → 검색100 프롬프트의 제목 규칙에 이 5종 + 지역 접두를 넣는다.

---

## 3. 도입부(첫 3~4문장) — 업종별로 확연히 다름

- **병원**: 공감형 오프너. "치아 상실이 일상에 미치는 영향", "거울 앞에 설 때마다 정수리가 신경 쓰이기 시작했어요". 환자 감정이입 → 정보로 전환.
- **변호사(우수)**: 질문·사례 후킹. "같은 도수치료인데 왜 병원마다 다를까요?", "이번 글에서는 불송치 결정을 받아낸 사례를 쉽게 풀어드리려고". 질문형 첫 문장.
- **변호사(스팸·안티패턴)**: "법치주의 나라에서 살아가기 위해서는 정해진 생활 방식을 준수하며…" 판박이 도입. 로엘·대륜 등 대량생산 글. **이건 우리가 피해야 할 나쁜 예 → AI 검수기가 '판박이 도입/의미 없는 총론' 감지해 리젝.**

---

## 4. 소제목 — 번호 리스티클 + 질문형

- 번호형: "1. 사건의 개요", "1. 초범인데도 실형?", "3가지 기준"
- 질문형: "무릎 통증, 왜 발생할까요?", "이 가격이 진짜 가능해?"

→ 검색100 프롬프트: 소제목을 번호 리스티클 또는 질문형으로 구조화하도록 강제.

---

## 5. 🚨 규제 준수 — 상위글이 실제로 지키는 회피법 (규제 검수 모듈이 학습할 핵심)

**병원(의료광고 심의):**
- **구체 금액 직접 제시를 피함.** 대신 "비용은 재료·장비·보철 종류에 따라 다르다", "그라프트당 단가·총 이식 모수·디자인 범위를 서면으로 안내" → "비용 구조 투명성"으로 우회. 특정 가격을 못 박지 않는 게 상위글 공통.
- 나쁜 예도 존재: "무릎통증 수술 없이 완치 가능합니다"(남성역 글) = **완치·보장 표현은 의료광고 위반 소지 → 규제 검수가 반드시 걸러야 할 금지 패턴.**

**변호사(변호사 광고규정):**
- 성공사례를 "무혐의/불송치/기소유예 받아낸 사례"로 노출하되, "반드시 이긴다·보장" 대신 "받아낸 사례" 과거 사실로 서술.
- 승소율·최고 등 절대 표현은 회피.

→ **규제 검수 모듈 룰 세트 초안:**
- 병원 금지: "완치/100%/부작용 없음/최고/유일" + 구체 시술가 단독 표기(할인·이벤트가 조장)
- 변호사 금지: "승소 보장/반드시/최고의 변호사/유일한" + 특정 결과 보장
- 공통 권장: 성과는 "~한 사례" 과거·개별 서술, 가격은 "구성 항목 안내" 방식

---

## 6. 페르소나 노출 방식 (시즌2 페르소나 세팅과 매핑)

- **변호사**: 블로그명·본문에 경력 전면. "경찰대/검사 출신 강정은 변호사", "13년 경력", "대표변호사 직접 상담". → 페르소나 세팅에 '전직 이력·경력연차·직접상담 여부' 필드 유효.
- **병원**: 실제 병원 계정명(세이프플란트치과의원·제니스정형외과·서울성모정형외과의원)으로 운영, 진료시간·역세권 위치 노출. → 페르소나에 '병원명·진료시간·위치(역)' 필드.

---

## 7. CTA

"1:1 문의", "상담 즉시 받아보세요", "대표변호사 직접 상담 ☎", 병원은 소프트하게 진료시간·위치·예약 안내. → 검색100 프롬프트 말미에 업종별 CTA 블록 삽입.

---

## 8. 시즌2 반영 액션 (프롬프트 3벌 + 규제 모듈로 직접 연결)

1. 병원·변호사 업종 선택 시 **노출 전략 기본값 = 검색 100%**.
2. **검색100 프롬프트**에 넣을 것: 지역+키워드 제목 공식(후킹구 5종), 번호/질문형 소제목, 정보 완결(비용은 '구성 항목' 방식), 업종 CTA.
3. **AI 검수기**: 판박이 총론 도입·의미 없는 반복 감지 → 리젝(변호사 스팸 안티패턴).
4. **규제 검수 모듈**: 위 5장 금지어·표현 세트를 병원/변호사 각각 초안으로 사용(전문가 감수는 미결 #3).
5. 크롤러(Camoufox)로 상위 3~5개 글의 실제 글자수·이미지 수·문단 구조를 재확인해 프롬프트 목표치 확정.

---

## 9. 이 분석의 한계 (미비점 수정 — 알고 쓰자)
- **표본 작음·한 시점 스냅샷**: 대표키워드 6개 상위 몇 글만. 네이버 알고리즘 바뀌면 무효 → **분기 1회 재분석** 권장.
- **본문 미검증**: 네이버 차단으로 제목+앞부분만 봄. 글자수·이미지수·소제목수는 크롤러로 실측 필요(위 5번).
- **검색형만 분석 → 홈피드 근거 없음**: 홈피드 노출 사례를 못 봄. 홈피드100(P1) 개발 착수 전 **홈피드 실제 사례 별도 수집·분석** 필요. (검색100·반반 P0 먼저인 이유이기도)
