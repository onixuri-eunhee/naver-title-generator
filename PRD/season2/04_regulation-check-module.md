# 업종별 광고 규제 검수 모듈 초안 (병원·변호사·기업)

> 시즌2 P0 필수(없으면 병원·변호사 출시 불가). 노출 전략 3벌 공통 적용.
> 설계 원칙: 원고 생성 프롬프트에 절대명령을 쌓지 않는다. **원고 생성 후 별도 검수 패스**로 돌려 위반 문구를 잡고, 불합격 시 해당 문구만 수정 지시 → 재작성. (글로벌 rule-stacking-check 준수: 룰은 결과 점검 체크리스트로.)
> 법령 근거(2026-07-03 확인): 의료법 제56조②·시행령 제23조·제27조③ / 변호사법 제23조② + 변협 「변호사 광고에 관한 규정」 제4조 / 표시광고법. 아래 룰은 이 조문을 문구 검출로 옮긴 것.
> ⚠️ 조문 기반이지만 여전히 **초안**. 문구 매핑의 정확성·최신 개정·개별 사안 판단은 변호사 감수 필요(미결 #3). 이 도구는 위반 소지 사전 경고이지 심의 통과 보장 아님([[07_disclaimer-draft]]).

---

## 1. 동작 방식

```
원고 생성 → [규제 검수 패스] → 위반 0 → 통과
                         └ 위반 있음 → 위반 문구·사유 리스트 반환
                                       → 원고 모델에 "이 문구만 규정에 맞게 고쳐라" 재지시(최대 2회)
                                       → 그래도 위반이면 발행 차단 + 사용자에게 경고 표시
```

- 검수 모델: 저비용 모델(Haiku/Sonnet)로 충분. 입력=원고+업종룰, 출력=위반 항목 JSON.
- 업종은 마이페이지 초기 세팅의 "업종 선택"에서 결정된 룰 세트를 로드.

### 1-2. 이미지 규제 검수 (🔴 8-1 #4 대응 — 텍스트만 봐선 안 됨)

의료법 제56조②5는 **"수술·시술 장면 등 직접적 시술행위 노출"을 금지** = 이미지 규제. 텍스트 검수만으론 못 잡으므로 이미지도 검수한다.

```
이미지 생성 → [생성 프롬프트 단계 사전 차단] + [생성 후 이미지 검수]
```

- **사전 차단(생성 프롬프트)**: 병원 업종이면 이미지 생성 프롬프트에 "수술·시술·환부·혈흔·의료행위 직접 묘사 금지, 시술 전후 비교 금지" 지시.
- **생성 후 검수(비전 모델)**: 생성된 이미지를 비전 모델로 확인 → 시술 장면·환부·과장 전후비교 감지 시 재생성. 변호사·기업은 이미지 규제 약해 사전 차단만.
- 이미지 검수 결과도 발행 전 체크리스트에 포함(7장).

## 2. 검수 출력 형식 (JSON)

```json
{
  "verdict": "pass | fail",
  "violations": [
    {
      "quote": "무릎 통증 수술 없이 완치 가능합니다",
      "rule": "medical.cure_guarantee",
      "reason": "치료 효과·완치 보장 표현(의료광고 심의 위반 소지)",
      "fix_hint": "'완치 가능' → '증상 완화를 기대할 수 있는' 등 단정 표현 제거"
    }
  ]
}
```

## 3. 병원·의원 룰 세트 — 의료법 제56조 제2항 12유형 기반

> 법령 근거: **의료법 제56조 제2항**(금지 의료광고 12유형) + **의료법 시행령 제23조**(구체 기준). 아래는 조문을 블로그 글에서 잡을 수 있는 문구 룰로 옮긴 것. (2026-07-03 국가법령정보센터·대한치과의사협회 가이드 확인)
> ⚠️ 블로그 글이 의료광고에 해당하면 매체·도달 기준에 따라 **사전심의 대상**일 수 있음(의료법 제57조). 우리 검수는 위반 소지 사전 경고이지 심의 대체 아님.

| rule id | 의료법 근거 | 잡아야 할 문구 | 권장 대체 |
|---------|-----------|---------------|----------|
| medical.cure_guarantee | 제56조②2 치료효과 보장·현혹 | "완치 가능", "반드시 효과", "무조건 낫습니다" | "증상 완화를 기대할 수 있습니다" |
| medical.comparison | 제56조②3 비교광고 | "타 병원보다 우수한", "○○치과보다" | 비교 삭제 |
| medical.disparage | 제56조②4 비방 | "다른 병원은 못하는" | 삭제 |
| medical.surgery_scene | 제56조②5 시술장면 노출 | (이미지 검수) 수술·시술 직접 노출 | 비노출 |
| medical.side_effect_omit | 제56조②6 중요정보(부작용) 누락 | "부작용 없는", "100% 안전" | 부작용·개인차 명시 |
| medical.unverified_claim | 제56조②7 객관적 근거 없음 | "통증 없는", 근거 없는 우위·수치 | 근거 없으면 삭제 |
| medical.article_style | 제56조②8 기사·전문가 의견형 | 기사/인터뷰 위장 형식 | 광고임을 명확히 |
| medical.price_bait | 제56조②11 비급여 할인·면제 오인 | "임플란트 39만원 특가", "오늘까지 반값" | 가격은 "구성 항목(재료·보철·범위)" 안내 |
| medical.superlative | 시행령 제23조 최상급 | "최고의", "국내 유일", "1위" | 삭제 또는 객관 근거 |
| medical.testimonial | 시행령 제23조 치료경험담 | "○○ 받고 다 나았어요" 환자 후기형 | 개별 경험담 지양 |
| medical.patient_inducement | 의료법 제27조③ 환자 유인 | "지인 소개 시 할인", "선착순 무료" | 삭제 |

> 상위글 확인: 좋은 글은 구체 시술가를 단독 표기하지 않고 "비용은 재료·장비·보철 종류에 따라 다르다"로 우회 → price_bait 회피 방식 그대로 채택.

## 4. 변호사·법무법인 룰 세트 — 변호사법 제23조② + 변호사 광고에 관한 규정 제4조 기반

> 법령 근거: **변호사법 제23조 제2항**(금지 광고 유형) + **대한변호사협회 「변호사 광고에 관한 규정」 제4조**(광고 내용 제한). (2026-07-03 국가법령정보센터·대한변협 확인)

| rule id | 근거 | 잡아야 할 문구 | 권장 대체 |
|---------|------|---------------|----------|
| legal.false | 변호사법 제23조②1 거짓 표시 | 사실과 다른 경력·실적 | 실제 사실만 |
| legal.fake_credential | 제23조②2 근거 없는 자격·명칭 | "국제변호사", 법적근거 없는 명칭 | 삭제 |
| legal.exaggerate_mislead | 제23조②3 과장·일부 누락 오도 | "업계 최다 승소", 유리한 사실만 | 균형 있게, 근거 |
| legal.win_guarantee | 제23조②4 / 규정 제4조 부당한 기대 | "반드시 승소", "무죄 보장", "승소율 98%", "석방율" | "~을 받아낸 사례"(과거·개별) |
| legal.superlative | 규정 제4조 최고·유일 | "최고의 변호사", "국내 1위 로펌", "유일한" | 삭제 |
| legal.disparage | 제23조②(비교·비방) | "다른 변호사는 못하는" | 삭제 |
| legal.client_disclosure | 규정(의뢰인 동의 없는 공개) | 동의 없는 의뢰인·사건 특정 | 익명·동의 확보 |

> 상위글 확인: 우수 글은 성공사례를 "무혐의/불송치 받아낸 사례"로 과거·개별 서술 → win_guarantee 회피. 이 서술 방식을 권장 대체의 기본값으로.
> ※ 「변호사 광고에 관한 규정」 일부 조항은 헌재 2021헌마619(2022.5.26) 일부 위헌 결정으로 효력 변동 → 감수 시 최신 개정본 반영 필수.

## 7. 발행 전 체크리스트 (3벌 공통 · 통과해야 발행 단계 진입)

- [ ] 규제 검수 verdict = pass
- [ ] 제목에 키워드·지역 포함
- [ ] 소제목 4~6개 존재
- [ ] 이미지 삽입 위치 마커 수 = 생성 이미지 수
- [ ] 출처 표기(인용 있을 경우)
- [ ] 페르소나 이력·병원명·위치와 본문 불일치 없음

## 8. 개발 메모

- 룰 세트는 코드 상수가 아니라 **업종별 편집 가능한 데이터(JSON/DB)**로 관리 → 전문가 감수 후 갱신·법 개정 대응 쉽게.
- 검수 패스는 노출 전략 3벌 어디서 왔든 동일 모듈 1개 호출(공통).
- 위반 재작성 실패 시 발행 차단은 하되, 사용자가 문구를 직접 수정해 강행할지 선택할 수 있게(책임 고지 후). 최종 발행 책임은 사용자.
